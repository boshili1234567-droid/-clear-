## 新增右键压缩

1. 打开轻解，点击 **资源管理器集成 → 启用右键压缩**。这项设置可以单独启用。
2. 在桌面或资源管理器选中一个或多个文件、文件夹，右键点击 **使用轻解压缩…**。Windows 11 请先点 **显示更多选项**。
3. 轻解会打开打包界面并带入所选项目，默认合并成一个 ZIP。同一目录的选项默认保存到该目录。可调整格式、名称、保存位置和重名处理，确认后点击 **开始打包**。
