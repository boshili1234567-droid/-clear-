## 打开普通 `.gz`

- 在 **浏览压缩包** 中选择 `.csv.gz`、`.txt.gz` 等文件。轻解会显示去掉末尾 `.gz` 的文件名，可预览支持的类型，也可复制或拖出文件。
- 在主窗口可批量解压普通 `.gz`。轻解核对解压数据的校验值和长度，校验失败时会清理临时文件。
- 普通 `.gz` 内容为只读。文本预览上限为 2 MiB，较大的 CSV 可解压后查看。发布包的 **试用文件** 中有 `背景曲线.csv.gz` 示例。

## 新增两种打包格式

- **GZIP（.gz）** 为每个文件分别生成一个压缩包，保留原扩展名。例如 `数据.csv` 打包为 `数据.csv.gz`。
- **TAR.GZ（.tar.gz）** 可以将多个文件和文件夹合成一个压缩包，保留目录结构、空文件夹和中文名称。需要时可在 **打包方式** 中选 **每个项目分别打包**。
- 主窗口和资源管理器右键的 **使用轻解压缩…** 都可选择这两种格式。密码加密适用于 ZIP。
