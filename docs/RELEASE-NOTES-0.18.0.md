## RAR 上限提高到 20 GiB

- 现在可创建和修改单文件最多 **20 GiB**、每包合计最多 **20 GiB** 的未加密单卷 RAR。上限按文件原始大小计算，每包最多 1,000 项。
- 写入器使用 64 位文件位置，按数据块读取和压缩。修改时在解码过程中核对文件内容，减少临时磁盘占用。打包和修改时仍会暂存压缩数据，所需空间取决于输入和输出大小。
- 可在「创建压缩包」中选择 **RAR（基础版）**，也可从资源管理器右键进入同一个打包界面。

## 验证

用含不同偏移标记的 20 GiB 测试文件验证了创建、浏览和重命名，并通过 7-Zip 26.06 独立解包，核对创建包和修改包的字节数与 SHA-256。795 项常规自动检查通过，详情见发布包中的 `TEST-REPORT.txt`。

在本机测试中，Windows 自带的旧版 `tar`（libarchive 3.5.2）将该 20 GiB 样本解到标准输出时，输出超过了文件声明的大小。轻解和 7-Zip 的解包结果通过核对。
